# Demo script (4 minutes)

> **Disclosure (say it and show it):** every learner in this demo is synthetic, illustrative sample data created for the demo. No real children's data has been used. The "Illustrative sample data" badge is visible on every screen that shows the demo class.

## Before recording
1. Sign in as the demo teacher and open **Settings → Classes → Reset demo class** (loads Class 3A with 12 synthetic learners, about 8 seconds).
2. Check AI is on (Settings → AI and privacy shows the model as ready). If AI is unavailable, the fallback is part of the story: show the labelled built-in set.
3. Generate one practice set for **N4 Subtraction, level 2** in advance (AI takes ~40 s on the free tier) and leave it **pending**.
4. Use a 1440×900 browser window. Close other tabs.

## Script
| Time | Screen | What to show and say |
|---|---|---|
| 0:00 | Landing | "Around 7 in 10 Nigerian children aged 10 can't read a simple sentence (World Bank/UNICEF estimates; link in the submission). Teachers with large classes can't see which skill each child is missing." |
| 0:20 | **Today** (Class 3A) | Greeting, summary strip, Next step card. Point to the **Class Ladder**: "Each dot is a learner on the rung they're working on. Five are on N4 subtraction." Click the N4 rung: the panel lists those learners with status and confidence. |
| 0:50 | **Check** on *Learner L* (not checked yet) | Start a numeracy check. Read one item aloud with the speaker, tap an answer, show the keypad and the teacher-only indicator. **End early** → results: "Not enough evidence yet… a few more questions are needed." "It never guesses from a handful of answers." |
| 1:30 | **Learner C** profile | Vertical skill ladders, "Working here" on N4. Click **Why?** on N4: sessions, weighted score, "provisional". Show the gap card with the 15-minute activity. |
| 2:00 | **Groups** | Rung boards. Drag a learner between boards (show Undo). Accept the N4 group. Note "Suggested by skill level. You decide." |
| 2:20 | **Practice** | Open the pending AI set: AI-drafted + Validated badges, the **validator report**, child-style preview with the answer key. Approve, then Assign to the N4 group. |
| 2:45 | **Child mode** (from Learner C's profile → Learner mode) | One question, tap the speaker, answer; kind feedback, no red, no score. Finish → "You tried 5 questions" with effort stones. |
| 3:05 | **Learner E** profile | The safeguard: strong history, then one bad day on N4 → "developing, retest suggested", **not** "not yet". |
| 3:20 | **Ask** | "Who needs subtraction support?" → learner chips (names shown locally; the model saw only codes). Then "Which learners have the best handwriting?" → "I don't have data for that yet." |
| 3:45 | **Insights** | First check vs latest ladders; Learner C moved up. Close: "Next: a pilot with 2–3 schools, Nigerian-language content, offline use." |

## Recovery lines
- AI slow or unavailable: "On the free tier this can take 40 seconds, and if Google's model is busy LearnSignal falls back to built-in practice, labelled so the teacher always knows."
- Anything else: the demo class can be reset from Settings in about 8 seconds.
