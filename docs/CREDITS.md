## AI assistance
- **Claude Code (Anthropic)** was used as a coding assistant to write and refactor code, tests and documentation under the team's direction. All output was reviewed and run; commits made with its help carry a `Co-Authored-By` line.
- **Google Gemini** runs inside the product (practice drafting and the Ask assistant). Model id is set by `GEMINI_MODEL`; tested with `gemini-3.6-flash` (earlier `gemini-2.5-flash` was retired for new users and `gemini-3.8-flash` was overloaded during testing).
